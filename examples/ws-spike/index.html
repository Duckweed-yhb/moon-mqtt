QoS2 发布握手： PUBLISH(pid=1) → broker 回 PUBREC(0x50 02 00 01) → core.feed() 自动产出 PUBREL(0x62 02 00 01) → broker 回 PUBCOMP(0x70 02 00 01) → 在途清空。 全程无手写握手字节，全由 core/ClientCore 纯函数驱动。 断线重连： onclose → on_transport_close() → state=Disconnected → 1s 后 reconnect attempt #1 → 新 CONNECT → 新 CONNACK → 自动 SUBSCRIBE(pid=2) + QoS2 PUBLISH → 继续收 PUBLISH。 最多重连 3 次（pid 递增 1→2→3）。
